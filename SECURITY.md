# Security policy

Report a vulnerability in the marketplace tooling, or a malicious or
compromised listing, privately through
[GitHub security advisories](https://github.com/vyasa-cms/marketplace/security/advisories/new)
or by email to security@vyasa.site — never in a public issue.

For Vyasa itself, see the [core security policy](https://github.com/vyasa-cms/vyasa/blob/main/SECURITY.md).
